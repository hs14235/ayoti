# AYOTI / DIVIDID

An illustrated world and narrative portfolio for Siri (Dividid), built around her original ink, watercolor, and mixed-media artwork.

## Local development

```bash
pnpm install
pnpm dev
```

## GitHub Pages

Every push to `main` runs the included GitHub Actions workflow and publishes the site at the repository's project URL. For this repository:

- `hs14235/ayoti` publishes to `https://hs14235.github.io/ayoti/`
- A fork at `dividid/ayoti` publishes to `https://dividid.github.io/ayoti/`

The workflow derives the owner and repository name automatically, so no paths need to be edited after a fork. If Actions are disabled on a fork, enable them from the repository's **Actions** tab and run the Pages workflow once.
